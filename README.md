TED 03 - Gerenciador de Persistência de Dados em Arquivos Estruturados (CSV e JSON)

Trabalho desenvolvido para a disciplina, com o objetivo de criar um sistema em Python para gerenciar a persistência de dados em arquivos CSV e JSON, garantindo segurança com o uso de 'with open', tratamento de erros e backup automático.
